The following course list is a curated set of resources selected to build the skills required for a project like Scanmex Logistics Tracker. The curriculum spans full-stack web development, DevOps and infrastructure fundamentals, and programming logic — the three pillars that underpin the ASP.NET Core 8 dashboard, the Android app, and the deployment pipeline that connects them.

## Web Development & Full Stack

<CardGroup cols={2}>
  <Card
    title="Full Stack Open"
    icon="graduation-cap"
    href="https://fullstackopen.com/es/"
  >
    University of Helsinki free course covering React, Node.js, GraphQL, and TypeScript. One of the most complete open-source full-stack curricula available, structured as a university module with exercises and project submissions.
  </Card>
  <Card
    title="Midudev Courses"
    icon="code"
    href="https://midu.dev/cursos"
  >
    A full catalogue of modern web development courses in Spanish covering React, Next.js, and more. Maintained by Miguel Ángel Durán and kept up to date with the current JavaScript ecosystem.
  </Card>
  <Card
    title="HTML from Scratch"
    icon="html5"
    href="https://midu.dev/curso/html-desde-cero"
  >
    Foundations of semantic HTML and web accessibility. Essential groundwork for anyone building Razor views in the dashboard or structuring content that screen readers and search engines can parse correctly.
  </Card>
  <Card
    title="Astro + Headless CMS"
    icon="bolt"
    href="https://midu.dev/curso/astro-cms-headless"
  >
    Building ultra-fast static sites with the Astro framework and a headless CMS architecture. Useful for understanding modern front-end delivery patterns that complement the MVC dashboard.
  </Card>
</CardGroup>

## DevOps, Tools & Logic

<CardGroup cols={2}>
  <Card
    title="Docker & DevOps"
    icon="docker"
    href="https://midu.dev/curso/curso-docker-devops/00-introduccion-a-docker/00-introduccion"
  >
    Containers, deployments, and infrastructure best practices. Covers packaging the ASP.NET Core dashboard and SQL Server into containers for consistent, reproducible deployments across environments.
  </Card>
  <Card
    title="OpenCode and Terminals"
    icon="terminal"
    href="https://midu.dev/curso/opencode-desde-cero/00-introduccion/00-que-es-opencode-y-terminales"
  >
    Command line, Unix environment, and developer workflow fundamentals. Covers the terminal skills needed to manage builds, run migrations, and work with version control effectively.
  </Card>
  <Card
    title="Programming Challenges"
    icon="trophy"
    href="https://retosdeprogramacion.com/"
  >
    MoureDev weekly programming challenges to sharpen logic and algorithm skills. Regular practice with data structures and problem-solving patterns directly improves the quality of route optimization and query logic in the Scanmex codebase.
  </Card>
</CardGroup>

<Note>
  These courses were chosen to complement the skills required to build the Scanmex system. Full-stack fundamentals map directly to the web dashboard built with ASP.NET Core 8 MVC; DevOps knowledge supports containerized deployment of the application and database; logic challenges keep programming instincts sharp for writing efficient SQL queries and clean C# business logic.
</Note>
