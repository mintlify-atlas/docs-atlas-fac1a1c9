Scanmex Logistics Tracker is a two-application system that gives logistics teams full visibility into their delivery fleet in real time. A **C# / ASP.NET Core 8 MVC web dashboard** lets office staff assign routes and watch drivers on a live map, while an **Android app running on Zebra rugged terminals** guides each driver, broadcasts GPS positions, and confirms deliveries with a barcode scan — all synced automatically to **SAP Business One**, with no double data entry.

## How the system works

The following five steps describe a typical day using the Scanmex Logistics Tracker, from route creation in the office to automatic SAP confirmation after each delivery.

<Steps>
  <Step title="Create the route">
    A logistics operator opens the web dashboard, pulls pending orders from SAP Business One, and assigns them to a driver as a sequenced route.
  </Step>
  <Step title="Driver receives stops">
    The driver opens the Zebra terminal app and sees all delivery stops plotted on a map — no printed sheet needed.
  </Step>
  <Step title="Real-time GPS tracking">
    While the driver is on the road, the app sends GPS coordinates to the server every few seconds. The dashboard map updates live.
  </Step>
  <Step title="Barcode scan confirmation">
    At each stop the driver scans the package barcode with the Zebra laser scanner. The delivery is confirmed instantly.
  </Step>
  <Step title="SAP syncs automatically">
    The confirmed delivery updates the order status in SAP Business One through the Service Layer REST API — no manual re-entry.
  </Step>
</Steps>
